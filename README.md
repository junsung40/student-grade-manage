학생 성적 관리 프로그램
학생의 학번, 이름, 국어·영어·수학 점수를 입력하고 평균과 학점을 확인하는 웹 프로그램입니다. PC와 스마트폰 웹브라우저에서 사용할 수 있습니다.
주요 기능
학생 정보 등록 및 전체 목록 조회
과목별 점수 입력과 평균 자동 계산
평균 점수에 따른 A~F 학점 표시
학번 또는 이름으로 학생 검색
평균 점수 및 이름순 정렬
전체 평균, 최고 평균, A 학점 인원 통계
학생 정보 삭제 및 예시 데이터 추가
브라우저 localStorage를 이용한 데이터 저장
사용 방법
웹사이트에 접속합니다.
학번, 이름, 국어·영어·수학 점수를 입력합니다.
학생 등록하기 버튼을 누릅니다.
검색창과 정렬 메뉴를 사용해 학생 정보를 확인합니다.
성적 통계 영역에서 전체 평균과 최고 성적을 확인합니다.
처음 사용하는 경우 예시 데이터 추가를 눌러 기능을 테스트할 수 있습니다.
학점 기준
평균 점수	학점
90점 이상	A
80점 이상 90점 미만	B
70점 이상 80점 미만	C
60점 이상 70점 미만	D
60점 미만	F
사용 기술
HTML: 웹페이지 구조
CSS: 화면 디자인과 스마트폰 화면에 맞춘 반응형 구성
JavaScript: 학생 등록, 평균 및 학점 계산, 검색, 정렬, 통계 처리
localStorage: 현재 브라우저에 학생 정보 저장
GitHub Pages 배포
이 저장소의 가장 바깥쪽(root)에 `index.html`과 `README.md`를 업로드합니다.
저장소의 Settings → Pages로 이동합니다.
Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
Branch는 `main`, 폴더는 `/(root)`로 선택하고 Save를 누릅니다.
배포가 완료되면 아래 주소에서 웹사이트를 확인합니다.
웹사이트 주소: https://junsung40.github.io/student-grade-manage/
데이터 저장 안내
학생 정보는 서버가 아닌 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서는 새로고침 후에도 정보가 유지되지만, 다른 PC나 스마트폰과 데이터가 자동으로 공유되지는 않습니다. 실제 개인정보 대신 예시 데이터로 테스트하는 것을 권장합니다.
