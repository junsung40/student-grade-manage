MY CAMPUS - 개인 학점 관리 프로그램
대학생이 자신의 과목별 성적과 졸업 진행 상황을 관리할 수 있는 웹 프로그램입니다. PC와 스마트폰 브라우저에서 사용할 수 있습니다.
주요 메뉴와 기능
1. 홈 대시보드: 누적 평점, 이번 학기 평점, 취득 학점, 졸업까지 남은 학점, 목표 평점을 확인합니다.
2. 성적 관리: 학기, 과목명, 이수 학점, 성적, 전공·교양 구분을 등록·수정·삭제합니다.
3. 학점 계산: 목표 누적 평점을 달성하기 위해 앞으로 필요한 평균 평점을 계산하고, 예상 성적 시뮬레이션을 합니다.
4. 시험 점수 계산: 현재 확보한 총점과 남은 시험 반영 비율을 입력해 목표 총점에 필요한 시험 점수를 계산합니다.
5. 장학금 목표: 장학금 목표 평점과 현재 누적 평점을 비교합니다.
6. 졸업 관리: 전체 졸업학점과 전공필수·전공선택·교양필수·교양선택·일반선택별 취득 학점을 확인합니다.
7. 성적 분석: 학기별 평점 그래프와 재수강 시 예상 평점 상승 효과를 확인합니다.
8. 수강 계획: 다음 학기에 들을 과목과 예상 성적을 등록해 예상 누적 평점을 계산합니다.
9. 설정 및 백업: 4.5·4.3·4.0 만점 기준과 성적 환산 점수, 재수강 반영 방식을 설정하고 JSON/CSV 파일을 저장·불러옵니다.
10. 성적표 출력: 성적 관리 메뉴에서 인쇄 기능으로 PDF 파일로 저장할 수 있습니다.
사용 방법
1. index.html을 더블 클릭하거나 GitHub Pages 주소로 접속합니다.
2. 설정 및 백업 메뉴에서 학교의 평점 만점과 A+, A0 등의 환산 점수를 확인하고 수정합니다.
3. 같은 메뉴에서 학교 포털의 졸업 기준을 확인해 총 졸업학점과 영역별 최소 학점을 입력합니다.
4. 성적 관리 메뉴에서 과목별 성적을 등록합니다.
5. 홈 대시보드와 학점 계산, 졸업 관리 메뉴에서 계산 결과를 확인합니다.
6. 데이터가 쌓이면 JSON 백업을 다운로드해 보관합니다.
평점 계산 방식
- 평점 평균은 과목별 성적 환산 점수 × 이수 학점을 모두 더한 뒤, 평점에 반영되는 학점 합계로 나누어 계산합니다.
- F는 평점 계산에 0점으로 포함하고 졸업 취득 학점에서는 제외합니다.
- P는 평점 계산에서 제외하고 취득 학점에 포함합니다.
- NP는 평점 계산과 취득 학점에서 제외합니다.
- 재수강 반영 방식은 설정에서 최신 성적, 가장 높은 성적, 모든 수강 기록 중 선택할 수 있습니다. 동일 과목명과 과목 구분을 기준으로 재수강을 판단합니다.
꼭 확인할 사항
- 초기 졸업학점은 미설정 상태입니다. 학교·학과·입학연도에 따라 요건이 다르므로 반드시 학교 포털의 공식 기준을 입력해야 합니다.
- 4.5/4.3/4.0 만점의 기본 환산 점수는 예시입니다. 학교의 실제 성적표 기준에 맞게 설정 메뉴에서 확인·수정해야 합니다.
- 재수강, P/NP, F의 처리 방식은 학교 규정과 다를 수 있습니다. 성적 분석 결과는 계획용 참고값이며 공식 성적 산출 결과를 대신하지 않습니다.
- 장학금은 평점 외에 최소 이수학점, 학과 석차, 소득구간 등 별도 조건이 있을 수 있습니다.
- 데이터는 현재 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않으므로 기기 변경 전 JSON 백업을 다운로드해 주세요.
GitHub Pages 배포
저장소의 최상위 폴더(root)에 index.html과 README.md를 업로드합니다. 저장소의 Settings → Pages에서 Source를 Deploy from a branch, Branch를 main, Folder를 /(root)로 선택하고 저장합니다.
